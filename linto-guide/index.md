# Linto guide

Linto is a local command-line toolbox for bibliography work, Quarto projects,
text processing, and development helpers. This guide is split into topic pages:

- [Installation and shell setup](install.md)
- [Group configuration](config.md)
- [Commands and invocation](commands.md)
- [BibTeX and bibliography workflow](bibtex.md)
- [Quarto workflow](quarto.md)
- [Shell completion](completion.md)

Use `linto help PAGE` to read a page in the terminal, for example `linto help
config`. `linto help GROUP` still lists the commands in a group, and
`linto help GROUP COMMAND` shows a command's help.

For a live list of active groups and commands, run `linto --help`.
