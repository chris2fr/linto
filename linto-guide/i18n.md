# Language and translations

Linto's messages (help, errors, progress and summaries) are translated. English
is the source language and French is currently the only translation. Option,
command and parameter names are never translated, so scripts and shell
completion behave the same in every language.

At present the `bib` group is translated. The other groups and the dispatcher
still show English only.

## Choosing the language

The language comes from the first of these environment variables that is set
and not empty:

1. `LC_ALL`
2. `LC_MESSAGES`
3. `LANG`

A value starting with `fr` (`fr_FR.UTF-8`, `fr`, `fr_CA`) selects French.
`C`, `POSIX`, `en` and `en_*` select English, and so does any language without
a catalog. A message with no translation is shown in English.

Beware that `LC_ALL` wins over the two others. A leftover `LC_ALL=C` keeps
Linto in English even when `LANG` is French.

```sh
LC_ALL=C linto bib json2db --help             # English
LC_ALL=fr_FR.UTF-8 linto bib json2db --help   # French
```

In fish, use `env` for one command, or set the variable for the session:

```fish
env LC_ALL=fr_FR.UTF-8 linto bib json2db --help
set -gx LC_ALL fr_FR.UTF-8
set -e LC_ALL        # back to LC_MESSAGES / LANG
```

## What is translated

- the `--help` text of each command and the `Usage:` line;
- error messages, written as `command: message` (exit status 2 for a usage
  error, 1 for a runtime error);
- progress and summary lines such as `3 entries -> out.json`, which go to
  standard error so that standard output stays machine-readable.

Not translated: option, command and group names, file and field names, the
output data itself, the guide pages and man pages (English), and a few internal
validation errors and the messages printed by the awk scripts.

## Adding a translation or a message

Catalogs are gettext `.po` files in `locale/`, named after the two-letter
language code (`locale/fr.po`). Each entry maps the English text to its
translation:

```po
msgid "unknown option: %s"
msgstr "option inconnue : %s"
```

- Keep the same placeholders on both sides: `%s` in shell messages, `{}` in
  Python messages.
- To add a language, copy `locale/fr.po` to `locale/XX.po` and translate the
  `msgstr` lines. No other change is needed.
- To add or change an English message in the code, update its `msgid` in every
  catalog, otherwise it falls back to English.

See `DEVELOPMENT.md` for how the code marks strings (`_()` in Python, `_` and
`die` in shell) and `tests/test_i18n.py` for the checks.
